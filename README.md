# Dr. Casa — sitio web

Sitio informativo de **Dr. Casa, Mantención y Remodelación de Hogar**, publicado en **https://drcasa.cl** con GitHub Pages.

Este repositorio contiene solo los archivos generados. El código fuente está en `jonhblackrc1/dr_casa`
(privado): para actualizar el sitio, ejecutar ahí `npm run build:informativo` y copiar el contenido de `out/` aquí.
